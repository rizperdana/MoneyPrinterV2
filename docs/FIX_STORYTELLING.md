# Mystery + Science Short-Form Content Framework

## 1) Title generation

The title must do **3 jobs**:

1. Create curiosity
2. Promise a payoff
3. Stay simple enough for all ages

### Good title formula

**[Strange fact] + [mystery] + [implied consequence]**

Examples:

* **This Should Not Exist**
* **Scientists Found Something Under the Ice**
* **A Signal Came From Deep Space**
* **This Object Breaks Normal Science**
* **What Was Hidden for 10,000 Years**

### Title rules

* Keep it **3–8 words**
* Use **common words**
* Avoid technical language
* Avoid clickbait that overpromises
* Make the first word strong: **This, Why, How, What, Scientists, Hidden**

### Title styles that work

* **Fear-based curiosity**: “This Should Not Be Possible”
* **Wonder-based curiosity**: “A Miracle Hidden in Space”
* **Puzzle-based curiosity**: “Nobody Can Explain This”
* **Discovery-based curiosity**: “Scientists Just Found This”

## 2) SEO definition

SEO for short videos is not only keywords. It is also **watch behavior optimization**.

### What the SEO should contain

* Main topic keyword
* Related keyword
* Emotional keyword
* Simple caption text

### Example

Topic: mysterious deep-sea creature

SEO set:

* **Main keyword:** deep sea creature
* **Related keyword:** unexplained ocean mystery
* **Emotional keyword:** terrifying, strange, shocking
* **Caption:** “A deep sea creature that scientists still cannot fully explain.”

### SEO rules

* Put the main keyword in:

  * title
  * description
  * first line of caption
* Use natural language
* Use 1 main topic per video
* Do not overload with tags

### Best keyword strategy

Use:

* 1 broad keyword
* 1 specific keyword
* 1 emotional hook

Example:

* broad: **space mystery**
* specific: **unexplained radio signal**
* emotional: **strange, shocking, eerie**

## 3) Crafting the description

The description should do 4 things:

1. Reinforce the title
2. Add context
3. Support SEO
4. Encourage engagement

### Description formula

**Hook line → short context → curiosity line**

Example:

> Scientists found something unusual in Antarctica.
> It looks natural at first, but some details do not make sense.
> What do you think it is?

### Description rules

* 1–3 short paragraphs
* Use simple words
* Include the main keyword naturally
* End with a question
* Do not write long explanations

### Good description style

* Clear
* Short
* Search-friendly
* Open-ended

## 4) How to make suitable images

Your images must do more than show the topic. They must create **mood**.

### Image goals

* Make viewers stop scrolling
* Create tension
* Support the story
* Feel readable on mobile

### Best image style for mystery + science

* Dark or muted background
* High contrast subject
* Strong focal point
* Few distracting objects
* Cinematic lighting
* Slightly unreal, but believable

### Image composition rules

* One main subject per image
* Use close-up when possible
* Show scale when needed
* Use visual contrast:

  * small object in a large space
  * light object in darkness
  * human figure near unknown object

### Good image progression

1. **Hook image** — most shocking or unusual
2. **Context image** — where it was found
3. **Detail image** — close-up of strange feature
4. **Twist image** — something that deepens the mystery
5. **Ending image** — unresolved, memorable frame

### What to avoid

* Too much text inside the image
* Overly busy scenes
* Low-detail faces or objects
* Generic AI-looking composition
* Repeated visual patterns with no new information

## 5) What animation should be implemented

Because your format is slideshow-based, animation must replace missing motion.

### Minimum motion layer

Every image should have at least:

* slow zoom in or out
* small horizontal drift
* slight parallax
* subtle light movement or particle effect

### Best animation types

* **Ken Burns zoom**
* **Parallax depth**
* **Slow camera push-in**
* **Subtle shake on reveal**
* **Flicker on mysterious objects**
* **Light sweep across the frame**
* **Particles, fog, dust, snow, static**

### Animation timing rules

* Change visual state every **1.5–3 seconds**
* Add a stronger motion event every **4–6 seconds**
* Use one “impact frame” before the twist

### Animation formula

* Start calm
* Increase motion gradually
* Peak at the twist
* End with slight tension, not full resolution

### What not to do

* Constant fast movement
* Random zooming
* Overdone transition effects
* Too many animated elements at once

## 6) What storytelling should be used

The best style is:

**Curiosity → tension → partial explanation → open loop**

### Core storytelling structure

#### 1. Hook

A strange claim or impossible visual.

#### 2. Context

Where it happened, who found it, what makes it unusual.

#### 3. Escalation

Add more detail that makes the mystery deeper.

#### 4. Twist

Reveal the contradiction.

#### 5. Partial explanation

Offer a possible answer, but not the full answer.

#### 6. Open ending

Leave one important question unresolved.

### Storytelling rules

* One idea per video
* One mystery per video
* One emotional tone per video
* Avoid over-explaining
* Leave space for imagination

### Best emotional modes

* awe
* fear
* wonder
* disbelief
* quiet tension

### Best audience-friendly tone

For general audiences, use:

* simple language
* short sentences
* clear sequence
* no technical overload
* no elite/scientific jargon unless translated immediately

## 7) How the voice dubbing should be

The voice is not just narration. It is part of the tension system.

### Ideal voice qualities

* calm
* low-pressure
* clear
* slightly mysterious
* not exaggerated
* not too fast

### Voice delivery rules

* Speak slower than normal conversation
* Pause before important words
* Lower energy on the hook
* Increase intensity slightly near the twist
* End with controlled uncertainty

### Recommended delivery pattern

* Hook: quiet and direct
* Context: steady and informative
* Twist: lower and sharper
* Ending: unfinished, thoughtful, eerie

### Voice script rules

* Use short lines
* Write for breath timing
* Avoid long complex sentences
* Make each line easy to speak naturally

### Good voice style example

> Scientists found something under the ice.
> At first, it looked ordinary.
> Then they noticed one detail that changed everything.

### Bad voice style example

> The object exhibited anomalous characteristics inconsistent with conventional geological formation models.

## 8) How the entire storytelling should be created

Think of the full video as a **micro-drama**, not a fact dump.

### Full creation pipeline

#### Step 1: Pick a single mystery

Examples:

* strange object
* unexplainable signal
* hidden discovery
* scientific anomaly
* ancient mystery with modern clues

#### Step 2: Find the most shocking angle

Ask:

* What is the weirdest detail?
* What is the most surprising contradiction?
* What is the one thing people will repeat?

#### Step 3: Build the hook first

The first line must create a question in the viewer’s mind.

#### Step 4: Create a visual arc

The images should move from:

* unknown
* context
* detail
* tension
* unresolved ending

#### Step 5: Write the voice script

The script should:

* be short
* be easy to speak
* reveal information slowly
* leave one big question open

#### Step 6: Add rhythm

Use:

* pauses
* image changes
* subtle motion
* text emphasis
* sound accents

#### Step 7: End on a loopable frame

The ending should feel like the beginning, so the video can replay naturally.

## 9) Best formula for general audiences

Your audience includes young and old viewers, so the content must be:

* easy to understand
* visually strong
* emotionally clear
* not too technical
* not childish

### Best universal formula

**Strange visual → simple explanation → bigger mystery → partial answer → open loop**

### Why this works

* young viewers get fast stimulation
* older viewers get clarity and structure
* both groups get curiosity and payoff

### Tone balance

* not too academic
* not too childish
* not too horror-heavy
* not too random

## 10) Practical structure for one video

### Suggested 20–30 second format

**0–2s:** hook image + hook line
**2–6s:** context
**6–12s:** detail increase
**12–18s:** twist
**18–24s:** partial explanation
**24–30s:** unresolved ending

### Suggested image count

* 4 images is workable
* 6 to 8 images is better
* 4 images is only enough if motion and pacing are strong

### Best rule

Each image must introduce **new information** or **new tension**.
